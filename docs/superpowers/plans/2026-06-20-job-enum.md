# Job enum on agents & skills — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Constrain the existing free-form `role` field on agents and skills to a closed `Job` enum, require it on agents, and filter the assignment skill-picker (and reject mismatches server-side) so only skills whose job matches the agent's can be bound.

**Architecture:** Reuse the existing `role` field — keep its DB column and JSON tag named `role`, change only its Go *type* to a new `domain.Job` enum. No DB migration, no API-contract change. The enum is the single source of truth, validated at every write path (config load, API create/patch) and mirrored as a small const in the frontend.

**Tech Stack:** Go (pgx v5, net/http, gopkg.in/yaml.v3), React + TypeScript (Vite, vitest), Postgres.

## Global Constraints

- Enum values: `developer` only, for now. Adding a job = one line in `domain.Jobs` (Go) + one line in `JOBS` (frontend `web/src/api/types.ts`).
- The `role` DB column (`agents.role`, `skills.role`, both `TEXT NOT NULL`) and the JSON field name `role` are **unchanged**. No migration.
- Do **not** touch `User.Role` / `RoleAdmin` / `RoleViewer` — separate auth concept.
- No DB CHECK constraint, no `GET /api/v1/jobs` endpoint (deliberate; see spec).
- Spec: `docs/superpowers/specs/2026-06-20-job-enum-design.md`. Work happens on branch `job-enum`.
- Go test package for `internal/domain` is `domain_test`. `internal/config` test package is `config_test`.

```go
package domain

// Job is the closed set of jobs an agent performs and a skill belongs to.
// Add a value here (and to the frontend JOBS const in web/src/api/types.ts)
// to introduce a new job.
type Job string

const JobDeveloper Job = "developer"

// Jobs is the canonical list of valid jobs.
var Jobs = []Job{JobDeveloper}

// Valid reports whether j is a known job.
func (j Job) Valid() bool {
	for _, v := range Jobs {
		if j == v {
			return true
		}
	}
	return false
}
```

```tsx
                ))}
              </select>
            )}
          </label>
        )}
```
